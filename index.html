Comment ça marche ?

Ce prototype enregistre les données dans le stockage local de ton navigateur. Elles restent sur cet appareil et ce navigateur. Exporte régulièrement une sauvegarde si tu ne veux pas perdre ton historique. La génération de planning est automatique selon des règles simples ; cette première version n'appelle pas de modèle d'IA externe.
